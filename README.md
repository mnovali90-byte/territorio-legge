# Il territorio legge

Quanto devi spostarti per incontrare un libro? Una mappa d'Italia costruita solo su dati aperti, con fonte, licenza e data di aggiornamento per ogni numero.

Lavori in corso.

## Dati

| Cartella | Contenuto | Fonti |
|---|---|---|
| `data/librerie/` | Librerie presenti sulle mappe aperte, assegnate al comune | Overture Maps Places, OpenStreetMap (`shop=books`), confini ISTAT |

I dati si aggiornano da soli una volta al mese con lo script `scripts/librerie_mappe_aperte.py`.

**Attenzione:** le mappe aperte non sono un censimento. Una libreria che manca qui può esistere davvero: questi dati dicono quali librerie *sono note*, non quali mancano.
